# Modality Gap in Frozen Vision-Language Models

Research project for **YZM5110 – Multimodal Learning** (Ahmet Yaylalıoğlu).

> The submitted version is pinned with the tag `v1.0-submission`.

## Research question

Does a training-free correction of the modality gap in frozen contrastive
vision-language models (CLIP, SigLIP) improve image–text retrieval, and
does it come at a cost to zero-shot classification?

- **RQ1 (reproduction):** Does the Table 1 gain of *Mind the Gap* survive when
  the shift is chosen on a validation split and the gap vector is estimated
  on non-test data? (The original code selects the shift on the test set.)
- **RQ2 (retrieval):** How does centering with train-split statistics change
  image→text and text→image Recall@K, separately?
- **RQ3 (cost):** Does it change zero-shot accuracy?
- **RQ4 (factors):** Does the effect depend on calibration source/size,
  re-normalization, and retrieval hubness?

Hypotheses were registered before the improvement experiments:
[`results/improvement/HYPOTHESES.md`](results/improvement/HYPOTHESES.md).
All numbers: [`results/SUMMARY.md`](results/SUMMARY.md).

## Reproduction target and methods

Weixin Liang, Yuhui Zhang, Yongchan Kwon, Serena Yeung, James Zou.
*Mind the Gap: Understanding the Modality Gap in Multi-modal Contrastive
Representation Learning.* NeurIPS 2022.
[arXiv:2203.02053](https://arxiv.org/abs/2203.02053) ·
official code: `third_party/Modality-Gap` (git submodule, MIT license).

All corrections work on cached, L2-normalized embeddings; no model is trained.
None of them is our invention:

| ID | Method | Origin |
|----|--------|--------|
| M0 | raw embeddings | — |
| M1 | subtract each modality's mean (train split), re-normalize | I0T_post (An et al., ACL 2025); GR-CLIP (Li et al., NeurIPS 2025) |
| M2 | subtract means, no re-normalization (ablation) | GR-CLIP form |
| M3 | Mind-the-Gap shift, δ chosen on validation | Liang et al. 2022 |
| M4 | norm(x − α·μ), α chosen on validation per retrieval direction | combination of M1 with a grid-selected scale (as in M3 and Sato et al. 2026) |
| C1 | shift by a random vector with the gap's norm (control) | — |
| M1-T | M1 with test-set means — **diagnostic only** | condition of I0T |

## Setup

Tested on Windows 11, Python 3.10.4, NVIDIA RTX 3080 Ti Laptop (16 GB),
CUDA 12.4 wheels. Full details: [`REPRODUCE.md`](REPRODUCE.md).

```bash
git clone --recurse-submodules <this repository>
python -m venv env-main
env-main/Scripts/python -m pip --isolated install torch torchvision --index-url https://download.pytorch.org/whl/cu124
env-main/Scripts/python -m pip --isolated install -r requirements-lock.txt
```

(`--isolated` only ignores machine-wide pip configuration; see REPRODUCE.md §2.
On Linux/macOS use `env-main/bin/python`.)

A second environment, `env-orig` (Python 3.9, torch 1.12), is needed **only**
to re-run the original Table 1 code; its setup is in REPRODUCE.md §2.

## Running

| Step | Command | Needs | Time (dev. laptop) |
|---|---|---|---|
| Smoke test (3 models, 32 pairs) | `python scripts/smoke_test.py` | GPU, weights download | ~1 min |
| Embedding caches | `python -m src.embed --model clip_b16` (also `clip_b32`, `siglip_b16`) | GPU, ~3.1 GB VRAM, ~0.7–1 GB disk per model | ~3 h per model on the laptop (thermal throttling; see REPRODUCE.md §8) |

## Notes on the protocol

- Means, gap vectors, δ and α come from train/validation splits only. Test
  sets are used once for evaluation. Exceptions are labeled: the original
  code's test-selected shift (B1/B2) and M1-T.
- Image→text and text→image are always reported separately.
- Uncertainty: 1,000-sample bootstrap over test queries (paired for
  differences); 3 calibration seeds.
- OpenAI CLIP weights must be loaded with the `-quickgelu` open_clip
  configs (REPRODUCE.md §7).
