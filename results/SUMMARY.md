# Results summary

Generated by `scripts/make_summary.py` from the files in `results/` (repository commit 37f3c2b at generation time; each result file also records the commit that produced it). Facts only; no interpretation. Numbers reported by other papers are kept in `results/paper_reported.json` and are labeled as such.

Models with results: CLIP ViT-B/16 (OpenAI), CLIP ViT-B/32 (OpenAI), SigLIP ViT-B/16 (WebLI).

Methods: M0 raw; M1 mean-centering + re-normalization (I0T_post / GR-CLIP form, train-split means); M2 centering without re-normalization; M3 Mind-the-Gap shift with δ chosen on validation; M4 norm(x − α·μ) with α chosen on validation per direction; C1 random-shift control; M1-OOD out-of-domain calibration; M1-T test statistics (diagnostic only). None of the methods is ours.
